Debug Keys

T
Cycle one to four pawns on a tile.
Y
Move the debug pawn cluster to the next tile.
Shift+Y
Move the debug pawn cluster to the previous tile.
Z
Toggle between far and near camera zoom.
Space
Roll the visible debug dice.
C
Toggle a container on the focused tile.
V
Cycle zero to four miners on the focused container.
B
Cycle the focused container owner color.
