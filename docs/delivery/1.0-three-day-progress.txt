Completed

In progress

Risks / bugs
- The official AWS host has shown severely degraded download speed for the approximately 39.5 MB Godot WebAssembly file, causing game startup to take several minutes in some tests. The same file loaded roughly 22 times faster from GitHub Pages.
- Inactive browser tabs are aggressively throttled by browsers. State recovery is now proactive, but the latest animation behavior still needs final multiplayer validation.
- Periodic synchronization currently sends complete snapshots every five seconds. This is acceptable for current playtests but should be optimized before larger-scale usage.
